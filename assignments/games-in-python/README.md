
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa um jogo da Forca em Python para praticar manipulação de strings, seleção aleatória, loops, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Implementar os palpites

#### Descrição
Complete o código inicial para selecionar uma palavra secreta e permitir que o jogador tente adivinhá-la, uma letra por vez.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra da lista predefinida.
- Exibir o progresso da palavra com letras ainda não adivinhadas ocultas, por exemplo, `_ _ _ _`.
- Solicitar palpites de letras e atualizar o progresso quando o palpite estiver na palavra.
- Controlar e exibir o número de palpites incorretos.

### 🛠️ Encerrar a partida

#### Descrição
Finalize o loop do jogo e informe o resultado quando o jogador adivinhar a palavra ou esgotar as tentativas incorretas.

#### Requisitos
O programa concluído deve:

- Encerrar a partida assim que todas as letras da palavra forem adivinhadas ou o limite de palpites incorretos for atingido.
- Exibir uma mensagem de vitória quando a palavra for adivinhada.
- Exibir uma mensagem de derrota e revelar a palavra secreta quando as tentativas se esgotarem.
